# Privacy Glasses

Privacy Glasses is an Obsidian plugin that provides controls for obscuring
on-screen text for improved privacy in public settings.

> **Original author:** Jill Alberts  
> **Original version:** 0.7.4  
> **Plugin ID:** `privacy-glasses`

## Status

This repository is an **unofficial community-maintained republish of the
original Privacy Glasses 0.7.4 release**.

The original author's GitHub account/repository is no longer available.
This repository exists to preserve access to the original release for users
who still need it.

### Important

This repository intentionally preserves the original 0.7.4 plugin files.
**No compatibility fixes or feature changes have been applied to this
release.**

If future maintainers publish modified versions, those changes should be
clearly documented and released as new versions rather than silently changing
the original 0.7.4 files.

## Installation

For manual installation, copy the following files into:

```text
<Vault>/.obsidian/plugins/privacy-glasses/
```

Required files:

```text
main.js
manifest.json
styles.css
```

`data.json` is included as part of the archived distribution and may be
copied as well.

Then enable **Privacy Glasses** under **Settings → Community plugins**.

## Compatibility

The original manifest declares:

```text
Version: 0.7.4
Minimum Obsidian version: 1.1
```

This is the compatibility information declared by the original release; it
